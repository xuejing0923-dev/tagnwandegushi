# 糖丸做多大呢？· 认识厘米

一节小学二年级数学公开课（苏教版二年级下册）的 HTML 课件：**34 页**，含影像、互动和 VR 全景。
课题《糖丸做多大呢？》——以"糖丸爷爷"顾方舟和 1955 年南通脊髓灰质炎疫情为情境，带孩子认识 1 厘米。

## 怎么放映

打开 `index.html`（建议用 Chrome 或 Edge），按 `F` 全屏。

| 键 | 作用 |
|---|---|
| `←` `→`／PageUp PageDown | 翻页（翻页笔直接可用） |
| `F` | 全屏 |
| `S` | 演讲者模式：提词器（逐字稿 + 下一页预览 + 计时器） |
| `N` | 底部备注　`O` 所有页缩略图　`T` 换主题 |
| `B` 或 `.` | 黑屏，停下来说话时用 |

需要动手的几页：第 3 页点一下放当年的影像；第 8 页在尺子上点 0／cm／数字；第 10 页点尺子上任意一段；第 11、23 页拖尺子；第 13 页点百宝盒里的东西分一分；第 26 页点问句看顾爷爷的回信；第 28 页点铅笔画出 4 厘米；第 34 页点"走进顾爷爷的展览"，按住画面左右拖，可以把展厅转一圈。
