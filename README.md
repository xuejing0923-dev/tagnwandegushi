# 糖丸做多大呢？· 认识厘米

一节小学二年级数学公开课（苏教版二年级下册）的 HTML 课件：**36 页**，含影像、互动、来电铃声和 VR 全景。
课题《糖丸做多大呢？》——以"糖丸爷爷"顾方舟和 1955 年南通脊髓灰质炎疫情为情境，带孩子认识 1 厘米。

## 怎么放映

打开 `index.html`（建议用 Chrome 或 Edge），按 `F` 全屏。

| 键 | 作用 |
|---|---|
| `←` `→`／PageUp PageDown | 翻页（翻页笔直接可用） |
| `F` | 全屏 |
| `S` | 演讲者模式：提词器（逐字稿 + 下一页预览 + 计时器） |
| `N` | 底部备注　`O` 所有页缩略图　`T` 换主题 |
| `B` 或 `.` | 黑屏，停下来说话时用 |

需要动手的几页：第 2 页是一通"视频来电"（**会响铃声**，点接听/挂断停）；第 4 页点一下放当年的影像；第 9 页在尺子上点 0／cm／数字；第 11 页点尺子上任意一段；第 12、24 页拖尺子；第 14 页点百宝盒里的东西分一分；第 23 页一把断尺；第 27 页点问句看顾爷爷的回信；第 29 页点铅笔画出 4 厘米；第 35 页点"走进顾爷爷的展览"可以拖着转一圈；第 36 页点"挂断"结束这通电话。

## 说明

- 整个文件夹拷到 U 盘或教室电脑上都能直接放，**不需要装任何软件，也不需要联网**。
- 想要一张张翻着看，可以打印成 PDF：`Ctrl/Cmd + P` → 目标选"另存为 PDF"。
- `img/` 里的照片如果换成同名文件，页面上会自动替换（缺哪张都不会报错，会显示线描占位）。
- 第 2 页的来电铃声在 `audio/来电铃声.mp3`，换铃声覆盖同名文件即可。
